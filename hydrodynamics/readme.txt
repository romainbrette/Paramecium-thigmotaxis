# Simulation Environment

This repository contains the MATLAB/Octave simulation code and Python
visualization code used to simulate and visualize flow generated by a
Paramecium held fixed near a surface.

The workflow consists of two main steps:

1. Run the MATLAB/Octave simulation to generate a set of simulation
   results.
2. Run the Python visualization script to turn those results into a
   final PDF figure.

The MATLAB/Octave simulation and Python visualization are intentionally
separated so that simulation results can be generated once and
visualized or revisited later.

In more detail:

1. Open MATLAB/Octave
2. Open MATLAB/run_simulation.m
3. Select the desired simulation parameters
4. Run run_simulation.m
5. A new folder is created in Results/ whose filename catalogs the mesh size and force ratio A_lm/A_og. This folder now contains .txt files that will be read into plot_piv.py.
6. Open/run Python/plot_piv.py
7. Select the newly-created Results folder
8. The final PDF is created inside that folder
